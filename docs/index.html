Stato del tracker

Dati pubblici di Instagram, raccolti ogni 8 ore. Le medie si riferiscono agli ultimi ~12 post. Engagement = (like medi + commenti medi) / follower. Le views sono disponibili solo per i reel.

Gestisci profili

La lista viene salvata cifrata con la password della dashboard: nel repository pubblico non si legge. Dopo il salvataggio il tracker parte da solo e i dati arrivano in pochi minuti.
    Token GitHub (serve per salvare)
    1. Apri github.com → nuovo token fine-grained.
    2. Repository access: Only select repositories → solo .
    3. Permissions → Repository: Contents = Read and write, Actions = Read and write.
    4. Genera il token e incollalo qui. Resta salvato solo su questo dispositivo.
